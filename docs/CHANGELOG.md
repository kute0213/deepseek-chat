# 更新日志

## 2026-11-24（分享、搜索与批量操作）

### 会话分享

- 新增 `share_links` 分享表（已安装站点首次调用自动建表），创建分享时保存当前可见分支的只读快照，后续修改会话不影响已分享内容。
- 会话页标题栏（桌面端与移动端）新增分享按钮，生成 `/share/{token}` 链接，可复制或直接打开。
- 新增公开分享页：展示标题、分享者、时间与完整对话，无需登录即可阅读；登录用户可点击「继续对话」，服务端把快照复制成该账号的新会话并自动打开。
- 「设置 → 数据管理」新增「我的分享」列表，可复制链接、打开分享页或撤销。
- 管理后台新增「分享管理」：支持搜索标题 / 用户名 / 分享口令、查看访问量与状态、撤销、恢复、删除；仪表盘增加分享统计，删除用户时同步清理其分享。

### 搜索

- 新增 `GET /api/sessions/search`，同时检索会话标题与消息正文，返回命中消息 ID 与上下文片段。
- 侧边栏新增搜索入口：输入关键词后防抖查询，结果按更新时间展示标题与片段，点击自动打开会话；目标消息不在当前分页时继续加载更早消息，定位后短暂高亮。

### 批量操作

- 侧边栏新增「批量管理」：进入多选模式后可逐项勾选、全选 / 取消全选，底部操作栏批量删除，删除前统一确认弹窗并汇总失败结果。

### 撤销某轮对话

- 回答操作区新增「撤销此轮」：删除该条提问、回答及其后的所有消息，同时清理这些消息派生出的其他分支，操作前二次确认，成功后立即同步服务端。

### 动画与交互

- 弹窗遮罩淡入、内容上浮缩放；菜单缩放淡入；会话项悬浮与选中颜色过渡；批量操作栏滑入；搜索结果与分享页消息逐条淡入；搜索跳转短暂高亮。
- 所有新增动画统一使用官方 `0.2s cubic-bezier(0.4, 0, 0.2, 1)` 缓动，并适配 `prefers-reduced-motion`。

## 2026-11-24

### 站点统一与命名

- 网站正式名称确定为 **DSW**，全称 **DeepSeekWebAPIChat**，所有页面（聊天页、管理后台、安装向导、404、服务协议）统一使用该名称。
- 新增语言文件 `app/lang/zh-CN.php` 与 `app/Support/Lang.php`，服务端页面不再写死站点名；前端默认名称、数据库默认值（`site_settings.site_name`）与旧安装的默认名迁移逻辑同步为 DSW。
- 聊天页、安装页、404、协议页、管理后台共用 `assets/ui.css`，控件、动画、弹窗、圆角、浅色/深色主题只有一份来源，删除各页面重复的样式定义。
- 删除遗留的品牌图标、品牌徽章与相关样式类。

### 聊天体验

- 消息分页大小由 10 条调整为 20 条（会话列表同为 20 条）。
- 向上滚动到顶部即触发加载更早消息，不再需要继续上滑；顶部显示「正在加载更早的对话」，没有更早记录时自动消失。
- 新增右侧消息导航：每条提问对应一个圆点，悬浮展开聊天记录预览，点击平滑跳转到对应消息；预览框滚动到顶部可继续加载更早消息并显示加载中。
- 从右侧导航触发加载时，主消息列表同步保持阅读位置，不会跳动。

### 数据导出

- 导出聊天记录改为纯客户端流程：浏览器先分页向服务端获取全部会话摘要，再逐个获取完整消息，最后在本地生成官方格式 ZIP；导出按钮旁显示实时进度百分比，数据不经过第三方服务。

## 2026-11-24（上一版本）

- 管理后台、安装向导、404 页统一为官方原版控件规范：胶囊按钮、40px 控件、24px 弹窗圆角、0.2s `cubic-bezier(0.4, 0, 0.2, 1)` 缓动。
- 管理后台原生 `confirm()` 替换为统一确认弹窗，支持遮罩点击、Esc、取消关闭。
