# 更新日志

## 2026-11-24

### 站点统一与命名

- 网站正式名称确定为 **DSW**，全称 **DeepSeekWebAPIChat**，所有页面（聊天页、管理后台、安装向导、404、服务协议）统一使用该名称。
- 新增语言文件 `app/lang/zh-CN.php` 与 `app/Support/Lang.php`，服务端页面不再写死站点名；前端默认名称、数据库默认值（`site_settings.site_name`）与旧安装的默认名迁移逻辑同步为 DSW。
- 聊天页、安装页、404、协议页、管理后台共用 `assets/ui.css`，控件、动画、弹窗、圆角、浅色/深色主题只有一份来源，删除各页面重复的样式定义。
- 删除遗留的品牌图标、品牌徽章与相关样式类。

### 聊天体验

- 消息分页大小由 10 条调整为 20 条（会话列表同为 20 条）。
- 向上滚动到顶部即触发加载更早消息，不再需要继续上滑；顶部显示「正在加载更早的对话」，没有更早记录时自动消失。
- 新增右侧消息导航：每条提问对应一个圆点，悬浮展开聊天记录预览，点击平滑跳转到对应消息；预览框滚动到顶部可继续加载更早消息并显示加载中。
- 从右侧导航触发加载时，主消息列表同步保持阅读位置，不会跳动。

### 数据导出

- 导出聊天记录改为纯客户端流程：浏览器先分页向服务端获取全部会话摘要，再逐个获取完整消息，最后在本地生成官方格式 ZIP；导出按钮旁显示实时进度百分比，数据不经过第三方服务。

## 2026-11-24（上一版本）

- 管理后台、安装向导、404 页统一为官方原版控件规范：胶囊按钮、40px 控件、24px 弹窗圆角、0.2s `cubic-bezier(0.4, 0, 0.2, 1)` 缓动。
- 管理后台原生 `confirm()` 替换为统一确认弹窗，支持遮罩点击、Esc、取消关闭。
