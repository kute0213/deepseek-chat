# 开发规范

## 1. 总体架构

- 后端：PHP 8.1+ + MySQL 5.7+ / MariaDB 10.4+，入口为根目录 `index.php`（首页输出、API 路由、`/install`、`/docs`、404 分发）。
- 前端：官方 deepseek-demo（React + TypeScript + rspack），源码位于 `frontend/`，构建产物输出到根目录 `index.html` 与 `static/`，与 PHP 接口同源部署。
- 管理后台：PHP 服务端渲染，入口 `admin/index.php`，页面在 `admin/pages/`，统一外壳 `layout.php`。
- 运行期数据：`uploads/`（配置、日志、附件、导入暂存），不提交 Git。
- 服务端公共能力：`app/Support/`（配置、数据库、认证、雪花 ID、请求响应、语言文件）；业务逻辑在 `app/Services/`；接口在 `app/Controllers/`。

## 2. 前端与 PHP 的结合方式

1. 浏览器访问 `/` 时由 `index.php` 读取构建产物 `index.html`，注入站点名称、`window.__SITE__` 等运行期信息后输出，因此默认首页必须是 `index.php`。
2. 前端所有业务请求走同源 `/api/*`；若服务器未开启伪静态导致 404，前端自动降级为 `/index.php?_r=/api/...`，查询参数（`limit`、`cursor` 等）必须原样保留。
3. 前端只持有站点信息与用户掩码后的 API Key，真正的 DeepSeek 请求全部由 PHP 服务端代理，Key 不下发浏览器。
4. 前端页面内的控件、弹窗、配色必须使用官方组件与主题令牌；不要新造一套按钮或弹窗样式。

## 3. 站点名称与文案

- 服务端统一从 `app/Support/Lang.php` 读取，词条在 `app/lang/zh-CN.php`。
- 新增或修改站点名称时，同步更新：语言文件、`site_settings` 默认值、安装向导默认值、前端 i18n 默认 `appName`、静态 404 / 协议页展示名。
- 不要在页面中散落写死站点名称。

## 4. 视觉与组件规范

- 服务端页面（管理后台、安装向导、404、协议页）统一引用 `assets/ui.css`，禁止再复制一份 `:root` 令牌或按钮/输入框样式。
- 官方组件参数：
  - 品牌蓝 `#3964fe`，悬停 `#5686fe`；暗色品牌 `#5686fe`。
  - 按钮胶囊圆角 `4096px`，主控件高 40px，后台按钮高 36px。
  - 弹窗圆角 24px，遮罩 `rgba(0,0,0,.36)` + `blur(2px)`，内容宽 380px、内边距 `22px 24px`。
  - 过渡统一 `0.2s cubic-bezier(0.4, 0, 0.2, 1)`。
- 必须同时适配浅色与深色模式（`prefers-color-scheme`）。
- 删除未使用的类、样式与资源，不保留“以后可能用到”的冗余代码。

## 5. 聊天数据与分页

- 消息分页大小固定为 20 条；会话列表每页 20 条。
- 打开会话先加载最近一页；向上滚动到顶部自动加载更早一页，并在顶部显示加载状态；没有更早记录时隐藏提示。
- 更早消息插入顶部后必须校正滚动位置，保证阅读位置不跳动；无论加载由消息列表还是右侧导航触发，都走同一套校正逻辑。
- 右侧导航圆点对应每条用户提问，悬浮展开预览，点击平滑跳转；预览列表滚动到顶部同样可加载更早消息。

## 6. 导入与导出

- 导出必须由浏览器向服务端获取全部会话与完整消息，再在本地生成官方格式 ZIP；导出过程显示进度百分比。
- 导入仍为整库覆盖，导入前必须确认；导入失败时保留原有数据。
- 归档格式保持与官方一致，继续兼容不带索引的旧版归档。

## 7. 安全

- 登录态使用 HttpOnly Cookie，数据库只存 Token 摘要。
- 所有写接口校验 `Origin` 与 `X-CSRF-Token`。
- 登录 / 注册 / 后台登录均校验图形验证码，答案只存摘要、一次性消费、5 分钟过期。
- API Key 按现有产品要求明文存入数据库，仅服务端使用，前端只展示后 4 位掩码。
- 生产环境只启用 HTTPS，并禁止直接访问 `app/`、`uploads/`、`docs/`、`frontend/`、`scripts/`、`.git`。

- 每次功能变更同步更新：根目录 `README.md`、`docs/CHANGELOG.md`、相关实现文档。
- `docs/README.md` 为根 README 的副本，修改 README 后需同步覆盖。
- 提交作者与提交者必须仅为项目所有者（`kute0213 <3846415473@qq.com>`），不得出现自动化代理账号。
- 提交前执行：

```bash
find app admin -name '*.php' -print0 | xargs -0 -n1 php -l
cd frontend && pnpm run type && pnpm run lint && pnpm run build
```

- `scripts/`、`uploads/`、`frontend/node_modules/`、`.pnpm-store/` 不提交 Git。
