# 隐私政策

本隐私政策说明 DSW（DeepSeekWebAPIChat）如何收集、使用、存储与保护你的信息。使用本服务前，请仔细阅读本政策。

## 一、我们收集的信息

1. **账号信息**：用户名、密码哈希、注册时间、角色与状态。密码仅以哈希形式保存，站点运营者无法查看明文密码。
2. **对话数据**：你创建的会话标题、消息内容、模型参数与时间信息。
3. **附件数据**：你主动上传的图片与文件，以及文件名、类型、大小等元信息。
4. **API Key**：你为调用 DeepSeek API 填写的密钥。为便于在你自己的设备之外继续使用，密钥按站点配置以明文或加密形式存储在服务端，仅用于发起模型请求。
5. **分享数据**：你主动创建的分享链接、所选消息快照、访问次数与创建时间。
6. **基础日志**：为保障安全与排查问题，服务端可能记录登录、管理操作等必要日志。

## 二、信息的使用

1. 用于提供对话、附件解析、历史记录、搜索、分享与导出等核心功能。
2. 用于账号鉴权、安全防护、故障排查与服务改进。
3. 不会将你的对话内容用于训练模型，也不会出售你的个人信息。

## 三、第三方服务

1. 对话生成依赖 DeepSeek API。你发送的消息内容会传输至该服务以生成回答，具体处理方式适用其隐私政策。
2. 除实现功能所必需外，我们不会向其他第三方披露你的信息。

## 四、信息存储与保护

1. 数据存储在站点运营者自行部署的服务器与数据库中。
2. 我们采取访问控制、密码哈希、接口鉴权等措施保护数据安全，但无法保证绝对安全。
3. 请勿在对话中提交身份证号、银行卡号等高度敏感信息。

## 五、你的权利

1. **查看与导出**：你可以在“设置 - 数据管理”中导出全部会话与附件。
2. **修改**：你可以随时修改用户名与密码。
3. **删除**：你可以删除单个会话、全部会话，或注销账号。注销后账号及相关数据将被删除且无法恢复。
4. **分享管理**：你可以查看并撤销自己创建的所有分享链接，撤销后链接立即失效。

## 六、Cookie 与本地存储

1. 本服务使用 Cookie 或等效令牌维持登录状态。
2. 前端会在浏览器本地保存主题、语言、输入草稿等偏好设置，你可以通过清除浏览器数据删除。

## 七、未成年人保护

未成年人应在监护人指导下使用本服务，监护人应对其使用行为进行监督。

## 八、政策更新

本政策可能随功能调整而更新，更新后会在本页面公布。继续使用本服务即视为接受更新后的政策。

## 九、联系我们

如对本政策或个人信息处理有疑问，可通过站点运营者公布的联系方式与我们联系。
