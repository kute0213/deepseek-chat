# Implementation Plan (English summary)

This is a concise English overview. The full, continuously updated plan is in `项目实现计划.md`.

## Goals

- Keep the official DeepSeek demo's UI, interaction, and animation quality.
- Provide a self-hosted PHP + MySQL backend for accounts, history, attachments, sharing, and API proxying.
- Serve the built front end from the PHP entry so the site works as a single same-origin application.

## Architecture

- `index.php` outputs the SPA shell and dispatches `/api/*`, `/install`, `/docs`, and `/404`.
- `frontend/` builds to `index.html` and `static/` at the root.
- `app/Controllers` exposes JSON APIs; `app/Services` holds sessions, files, shares, imports, and admin logic; `app/Support` holds config, database, auth, snowflake IDs, and language helpers.
- `admin/` is a server-rendered console sharing `static/site/ui.css`.
- `docs/` stores Markdown documentation; `docs/index.php` serves the `/docs` route so the real directory never produces a 403.

## Data model

`users`, `auth_tokens`, `sessions`, `usage_archives` (deleted-session token totals), `files`, `session_files`, `staging_sessions`, `staging_files`, `id_sequence`, `login_attempts`, `captchas`, and `site_settings`.

## Core flows

1. **Chat**: streaming requests proxied by PHP, branch switching, retries, editing, attachments, speech.
2. **History**: cursor-paginated session list and message paging (20 per page) with scroll-position preservation.
3. **Sharing**: select messages in the chat (paired user/assistant turns), snapshot them, and serve a read-only page. Links can be revoked.
4. **Search**: search titles and message bodies; open the result at the matching message window.
5. **Undo**: truncate a round and all later messages, syncing to the server.
6. **Admin**: users, sessions, shares, settings, CSV export; local switching without full reloads.
7. **Docs**: `/docs` renders Markdown with a collapsible list and Chinese/English versions (`name.md` / `name.en.md`).
